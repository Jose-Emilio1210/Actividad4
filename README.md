# Cannon.py

Juego realizado en Python utilizando Turtle, donde el jugador dispara proyectiles para destruir objetivos en movimiento.

# Modificaciones realizadas

Se realizaron las siguientes mejoras al código inicial:

- Se aumentó la velocidad del proyectil.
- Se aumentó la velocidad de movimiento de los objetivos.
- Se mejoró la dinámica del juego para hacerlo más rápido y desafiante.
- El juego no termina y las balas que se salgan fuera de la ventana se repocisionan.

# Controles disponibles

- Click izquierdo del mouse → disparar proyectil hacia la dirección seleccionada.

# Características del juego

- Los objetivos aparecen aleatoriamente.
- Los proyectiles son afectados por gravedad.
- Los objetivos desaparecen al ser impactados.
- El juego termina si un objetivo sale de la pantalla.

# Ejecución

Ejecutar el programa con:

python3 cannon.py
